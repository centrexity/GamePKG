# Portable NTSTATUS conversion

The player adapter in `../gamepkg_x86_status.c` implements the value conversion
for `RtlNtStatusToDosError` using the pinned Wine 9.0 compatibility profile. It
preserves customer-defined codes, normalizes HRESULT-from-NT error codes,
handles the three encoded-Win32 high words, searches all 43 mapping ranges and
returns ERROR_MR_MID_NOT_FOUND for unknown codes. All 1,586 table entries are
retained, including holes and mappings that return a full exception/HRESULT
value. Logical `uint32_t` arithmetic avoids host Windows types and signed shifts.

The runtime does not call host ntdll or use host TEB/last-status state as guest
state. Original guest caller code continues normally after the import. The host
adapter separately handles its one stack argument, checked return and retirement.
The mapping helper has no RAM, GPR, FP, IF, IRQL, native-handle or instruction
retirement side effects.

## Sources, license and regeneration

Original sources are retained byte for byte in `upstream/`, pinned to Wine tag
`wine-9.0`, commit `fd1153552d779e1ac14b0b1c48fbd1cde894eb0a` from
[Wine's repository](https://github.com/wine-mirror/wine/tree/fd1153552d779e1ac14b0b1c48fbd1cde894eb0a).
`upstream-lock.json` records every original path and SHA256. The unchanged
`error.c`, `error.h`, `winerror.h`, `ntstatus.h` and `COPYING.LIB` are included.
The adapted converter and numeric table are LGPL-2.1-or-later; retain original
copyright notices and the complete license in [upstream/COPYING.LIB](upstream/COPYING.LIB).
This component's license is separate from the root Apache license.

`node tools/generate_takedawn_status.mjs` regenerates the numeric table, test
inputs and original NoTeb reference excerpt offline. `--check` verifies all
locked inputs and exact generated bytes. The parser accepts only literal
numbers, reviewed constant wrappers and identifier aliases; it does not execute
upstream expressions. It validates range ordering, offsets and every annotated
status. Players require neither Node, Wine nor a Windows DLL for conversion.

Keep the complete corresponding modified source, build scripts, license and
source-access information with any binary incorporating this LGPL component.
Native delivery must preserve the ability to rebuild and relink with a modified
component. The player adapter is a separate C translation unit; the maintainer
reference and oracle are not linked into player builds. These private
qualification binaries are not a signed or published player package.

## Qualification and limits

`tools/check_takedawn_status.sh` compares 730,816 cases against the separately
compiled original table/NoTeb body and both installed Wine 9.0 ntdll conversion
exports. It covers every source row, range boundaries, customer/normalization
variants, all 65,536 low words under eight relevant high words, and 200,000
deterministic full-word samples. Native Windows GCC and mixed Clang/GCC builds
emit the same corpus as the original-source host reference. That independent
native-generated corpus is replayed on ASan/UB/leak host, actual Linux32 UB,
MIPS32 big-endian/QEMU, GCC Windows32/Wine and mixed Windows32/Wine. Pending
emulated x87/MMX/XMM and GPR banks remain unchanged. Native conversion also
preserves the host Win32 last-error marker around each tested call.

The `GPKNTD01` corpus is explicitly little-endian, 5,846,552 bytes, SHA256
`8fee9d8937127372b77ee40bc66fc20d31ae7619cddefe3825b54a33f3d63f7e`.
All runs have digest `d3f9f29c390e282b`; cases are individually compared, so the
digest is an artifact identity rather than the sole correctness check.

This qualifies the pinned mapping profile, not all 2^32 inputs against every
Windows/Xbox revision. Cxbx also delegates conversion to native ntdll, but exact
original retail Xbox extended-status-table parity remains unverified. This does
not establish physical Windows execution, whole-game endianness or playability.
The reference includes a type/annotation shim and an unchanged extracted NoTeb
body; only the adapted numeric converter is part of the player runtime.
